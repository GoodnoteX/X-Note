# X-Note

大家好，这里放的是我在过去半年多里关注和精读的热点论文、技术博客，以及学习过程中整理的一些知识点（会陆陆续续的新增进来）。内容主要围绕 Agent、推理与规划、记忆、知识图谱、Harness 和上下文工程，包括论文精读、技术博客解读和工程手册整理。

建这个仓库，也是想给自己留一个持续学习和回头梳理的地方。AI 发展太快，很多方法和工具可能几个月就变了，做这一行，得对这些变化保持足够的敏感度。光刷到一个热点、记住几个名词还不够，总得花时间把它弄明白，看看它解决了什么问题，又能用到哪里。希望通过这些阅读和记录，慢慢形成自己的判断，在新的方向和机会出现时，能早点看见，也有能力抓住。

文章以 Markdown 格式放在仓库根目录，配图统一保存在 `images/` 文件夹中，下载后就可以一起阅读。

## 阅读前提醒

> **GitHub 网页预览可能无法完整显示部分公式**，有时会直接显示公式源码，或出现排版错乱、渲染报错。建议下载整个仓库，在本地阅读。
>
> **我自己用的是 Obsidian，目前本地打开和查看公式都没有问题。**

下载时记得带上 `images/` 文件夹，并保留它与文章的相对位置。如果只下载单篇 Markdown，配图会无法显示。用 Obsidian 打开整个仓库文件夹后，可以切换到阅读视图查看文章。

## 关于这些笔记

这些文章都是我对相关论文、博客和工程资料的中文精读笔记，会沿着原文展开，保留方法、图表、实验和推导等内容，建议配合原文一起阅读。

如果只想先了解论文的核心方法，可以跳过前面的背景介绍，从方法部分开始读，通常在第二节或第三节；具体以文章目录为准。博客解读的重点分散在各个章节，更建议顺着全文阅读。
